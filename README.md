## 打开方式

1. **电脑/手机浏览器**：直接打开 `index.html` 即可。
2. **微信内打开**：把整套静态文件部署到任意静态托管服务（如 Vercel、Netlify、腾讯云开发），然后发送链接到微信。
3. **演示密码**：`123456`

## 本版已实现

- 登录页（个人访问权限演示）
